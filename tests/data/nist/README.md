# NIST ASD regression data

These unmodified CSV exports are copied from the Figgy renderer examples at
revision `e68922d73ca6bc43c86adcd081355a67e0b98ef3`, under
`crates/renderer/examples/data/nist`. They contain He I, Cu I and Ar I levels
and lines, including the original references and numeric qualifiers.

Source database: [NIST Atomic Spectra Database](https://physics.nist.gov/PhysRefData/ASD/).
The fixtures keep importer checks offline and exercise actual exported CSV
quoting, units and cross-table level references.
