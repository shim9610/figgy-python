`e68922d73ca6bc43c86adcd081355a67e0b98ef3`에 고정되어 있다.

## 재현 후 수정한 문제

- **다른 Figure의 데이터 덮어쓰기:** 에너지레벨의 복사 코드를 적용하면 대상
  에너지가 `100 → 1`로 덮였다. 고급 차트의 내보낸 코드는 이제
  `apply_settings(..., preserve_data=True)`를 사용한다. 대상의 준위 에너지와
  전이 메타데이터를 유지하고 범주 ID·컬럼 연결·다이어그램 토폴로지가 다르면
  커밋 전에 거부한다. 3개 범주의 막대차트에 2개 범주 설정을 적용하던 문제도
  같은 경로로 거부한다. 직접 `apply_settings`의 기본 동작은 전체 설정 교체다.
- **boxplot·hexbin 코드 재적용 실패:** 범례의 `series_id` 메타데이터를 텍스트
  공개 API에서 보존하고, 육각형 격자는 원자적인 설정 재적용 경로를 사용한다.
- **스타일 구조 혼합:** 벡터용 `width_px` 기본값이 CategoryBars, BoxPlot, Radar
  스타일에 들어가 유효성 검사에 실패했다. 벡터 기본값의 적용 대상을 제한했다.
- **다이어그램 위젯 초기화 실패:** 에너지레벨·파인만은 레코드로 구성되어
  숫자 컬럼을 읽지 않는데, 초기 로그 범위 조회가 가상의 X/Y 컬럼을 읽었다.
  공통 범위 처리에서 다이어그램의 준위와 배치 좌표를 사용한다.
- **입력 변환:** NumPy 숫자·좌표 배열과 문자열 라벨을 다이어그램 문서 값으로
  변환한다. 누락된 필드·중복 ID·없는 전이 끝점을 커밋 전에 검사한다.
  파인만의 배치 방향 인자도 노출했다.
- **기본 차트 스타일 API:** 공통 시리즈로 바뀐 막대·박스·레이더에서
  `ax.chart.get_style/set_style/set_label_style`과 Artist의 색·선 두께 조회 및
  변경을 지원한다. 원본 컬럼과 업로드 횟수가 유지되는지 검사했다.
- **브라우저 에너지레벨 선택 정보:** 상류 WebChart가 `ValueLabel.part`를 무시해
  `selected label no longer exists`로 실패했다. 우리 편집기는 해당 레코드의
  문서 메타데이터를 읽는다. 상류 재현은 영문
  [figgy #318](https://github.com/shim9610/figgy/issues/318)에 등록했다.

## 남아 있는 문제와 배포 전 작업

### 구형 차트 편집 API와 값 라벨

공통 시리즈용 `ax.chart`에는 아직 `series`, `cell`, `set_value_labels`,
`decoration`, `set_plot_bounds`가 없다. 실제 호출에서 AttributeError를 재현했다.
기본 스타일 API 복구만으로 이 이름 기반 편집 API 전체가 호환되는 것은 아니다.

새 막대차트의 기본 `labels.placement`는 Auto지만 `labels.text`가 채워지지 않는다.
표시 문자열을 데이터에서 생성하는 호스트 처리가 필요하다. 복사 코드에서는
다른 데이터셋의 계산된 라벨을 가져오지 않도록 대상의 문자열을 유지하며,
라벨 형식이 달라지면 명시적으로 거부한다. 대상 데이터로 라벨을 다시 포맷하는
편집 경로를 완성해야 한다.

### Python 스타일 프리셋

스타일 토큰의 기존 `bounded` 영역이 공통 시리즈에 완전히 연결되지 않았다.
예를 들어 `dpi=72`, `dashboard.operations`의 범주 막대 outline_width는
0.5를 지정하지만 생성된 CategoryBars는 1.0을 유지한다. 막대·박스·레이더의
가족별 스타일과 명시적 인자 우선순위를 공통 모델에 연결해야 한다.
이는 렌더러의 `gallery`, `cool-slate`, `midnight`, `warm-paper` 테마와 별도 경로다.

### SVG/PDF 인쇄 크기

파일 출력은 동작하지만 렌더러의 96 논리 픽셀/인치 단위가 그대로 적용된다.
`figsize=(4, 3)`의 실제 출력 크기를 SVG 루트 크기와 PDF MediaBox에서 확인했다.

| Figure DPI | SVG 크기 / PDF 페이지 크기 | 인치 환산 |
| --- | --- | --- |
| 72 | 216 × 162 pt | 3 × 2.25 in |
| 96 | 288 × 216 pt | 4 × 3 in |
| 120 | 360 × 270 pt | 5 × 3.75 in |

Python의 figsize/DPI 관례에 맞춰 물리 크기를 전달하거나 변환해야 한다.
scale로 데이터 래스터 해상도를 올리는 기능은 이 페이지 크기 문제를 해결하지 않는다.

### 회귀 검사 이관

기존 검사 중에는 없어진 최상위 `categorical`, `boxplot`, `radar` 문서와 radial의
옛 `title` 필드를 직접 참조하는 경우가 있다. 공통 시리즈·문서의 리소스 연결,
실제 숫자 값과 픽셀을 검사하도록 바꿔야 한다. 이름 기반 편집 API가 없는 경우와
프리셋 누락처럼 실제 호환성 오류도 함께 존재한다. 남은 실패를 모두 테스트의
문제로 분류하지 않았으며, 검사 의미를 보존한 이관과 재검증이 필요하다.

## NIST 입력 편의성

`read_nist(levels, lines=None)`는 CSV 경로·본문·텍스트 스트림·테이블을 읽는다.
준위 ID를 configuration/term/J로 만들고 이온화 한계를 분리한다. 단위·수치 한정
기호·불확도·참고문헌을 보존하며 전이 끝점을 연결한다. 표에 없는 준위를 가리키는
전이는 기본적으로 오류이며 `unmatched='skip'`을 명시한 경우에만 개수를 기록하고
제외한다. URL 다운로드, 단위 변환, 없는 전이 추론과 미세구조 중심값 계산은 하지 않는다.

오프라인 회귀 데이터는 렌더러 예제에 있던 실제 NIST CSV다.

| 데이터 | 준위 | 전이 | 이온화 한계 | 연결 누락 |
| --- | --- | --- | --- | --- |
| He I | 59 | 111 | 1 | 0 |
| Cu I | 35 | 69 | 1 | 0 |
| Ar I | 43 | 51 | 1 | 0 |

입력 원본과 출처는 [NIST 회귀 데이터](../tests/data/nist/README.md), 실행 가능한
입력·보존 검사는 [test_diagram_inputs.py](../tests/test_diagram_inputs.py)에 있다.
호스트 검사는 [test_interaction_parity.py](../tests/test_interaction_parity.py),
배포 순서는 [PUBLISHING.md](PUBLISHING.md)를 따른다.
