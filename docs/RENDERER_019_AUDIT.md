### 11월 18일 추가 점검

이전의 기본 회귀 통과 수는 실제 마우스 조작 전체를 검증했다는 뜻이 아니다.
편의 API, 편집기 입력 경로, 출력·데이터 보존을 구분해서 확인한다.

- 에너지 준위와 Feynman 다이어그램에 ID 기반 행 편집 핸들을 추가했다.
  라벨·서식·위치·전이 끝점·입자 종류·선 굽힘·정점 마커·운동량 화살표를
  편집하며, setter는 선택한 핸들을 반환한다. 길이는 포인트 단위를 사용한다.
- 기본 스타일과 비어 있는 라벨을 직렬화하지 않은 모델도 편집기에서 수정할 수
  있게 했다. 공통 시리즈의 이름 입력란을 추가하고 `/`가 포함된 ID 검색을 고쳤다.
- 브라우저 선택 경로에 남아 있던 제거된 `set_picked_points()` 호출을 없애고,
  Feynman 클릭 결과의 `index`를 저장용 선택 필드로 변환한다. 같은 점의 재클릭
  선택 해제와 화면 배율에 따른 키보드 이동도 검사한다.
- 정점·전파선·값 라벨 드래그는 렌더러의 공개 이동 API로 처리한다.
  `sync()`는 편집 수락을 기다리고, GPU 화면 완료는 준비·출력 동작에서 기다린다.
- 브라우저 BoxPlot Fit과 전송 버퍼 해제 후 방향·누적 모드를 바꾼 notebook Fit을
  수정했다. 이미 보유한 통계와 공개 범위 맞춤 API를 사용한다.

추가 API 회귀는 source 공유 다이어그램 선택을 포함해 **41개 통과**했다.
실제 입력은 다음 묶음으로 나눠 확인했다.
서로 다른 실행과 재검증 결과이며 전체 편집기 검증으로 합산하지 않는다.

| 실제 입력 검사 | 통과 | 확인한 동작 |
| --- | --- | --- |
| 다이어그램·값 라벨 | 12 | 준위·정점·전파선·운동량 라벨과 선 굽힘 드래그, 되돌리기, 원본 보존 |
| 레코드 선택 | 6 | 준위·정점 클릭, 정점 이동, 같은 점 재클릭 선택 해제 |
| 지연 프레임·키보드 | 5 | GPU 프레임 대기 중 편집 수락, 제목 이동, 키보드 이동 |
| 설정·주석·radial 창 | 17 | 시리즈 이름, 마커·운동량 화살표, 주석 8종, radial 창 검사 |

설정·주석 묶음의 첫 실행에서 접힌 설정과 스크롤 메뉴의 가려진 항목을 클릭한
3개 테스트를 수정해 각각 재통과시켰다. 실제 native와 Jupyter 입력을 사용한다.
기존 막대·박스·radial 공통 조작 3개도 통과했지만, 브라우저 레이더의 첫 데이터
선택은 아래 #327 때문에 시간 제한을 넘었다. 실제 호스트 전체 묶음이 통과한
상태는 아니다. 현재 pin의 최종 기본 전체 회귀는 **1,823 통과 / 실패 0 /
201 건너뜀 / strict xfail 3**이다. 예상 실패 3개는 아래 #325이며,
건너뛴 호스트 검사를 통과한 것으로 세지 않는다. 자산·배포 사전 검사는
**110 통과**했다. 실행 로그·소스 해시는
[11월 18일 검증 자료](measurements/renderer-019-usability-audit-20261118.json)에 기록한다.

상위 WASM에서 준위 선·전이의 선택 정보 조회가 잘못된 분기로 들어가는 문제는
직접 재현해 영문 이슈 [figgy #321](https://github.com/shim9610/figgy/issues/321)에
보고했다. #318의 라벨 수정과는 별개의 선택 종류다. 이후 상위 수정이 반영되어
브라우저는 공개 API를 직접 호출한다. native도 공개
`energy_level_records`로 source 공유 시리즈의 레코드를 찾는다. 수치 원본 배열을
보관하지 않으며, 임시 브라우저 처리는 제거했다.

### 수정 범위

- **이름 기반 편집:** 공통 시리즈로 바뀐 막대·박스·레이더에 `series`, `cell`,
  `set_value_labels`, `decoration`, `set_plot_bounds`, 방향 전환과 초기화 API를
  연결했다. 범주·시리즈 ID로 편집하며 기존 데이터 컬럼을 재업로드하지 않는다.
  개별 레이더 spoke 라벨은 새 `Category.label_offset`에 연결했다.
- **값 라벨:** 렌더러의 공개 `format_labels`, `format_box_plot_labels`,
  `format_radar_labels`로 실제 값·중앙값·표본 수를 포맷한다. native는 필요한 값을
  GPU에서 일시적으로 읽으며 원본 배열을 보관하지 않는다. notebook은 전송 버퍼가
  있을 때 그 버퍼를 쓰고, 전송 완료 후에는 브라우저 GPU 데이터로 처리한다.
  형식 변경은 재계산하지만 색·스타일 편집은 사용자가 지정한 라벨 문자열을 유지한다.
- **프리셋:** 기존 `bounded` 토큰을 공통 시리즈와 소유 패널에 연결했다.
  원본 데이터·범주·축 범위는 유지하며 명시적 생성 인자가 프리셋보다 우선한다.
  스타일 추출·재적용에도 차트 종류별 스타일과 인치당 해상도에 따른 길이 변환이 적용된다.
  벡터용 역할·기본 스타일이 다른 차트 종류의 구조에 들어가던 문제도 막았다.
- **인쇄 크기:** 렌더러의 96 논리 픽셀/인치 출력을 Figure DPI에 맞춘다.
  SVG는 루트의 물리 크기를, PDF는 페이지와 내용을 함께 변환한다.
  배율은 출력 해상도를 바꾸며 페이지의 인치 크기는 유지한다. native 저장 창과
  notebook의 비동기 출력 모두 같은 규칙을 따른다.
- **호환성 검사:** 없어진 최상위 `categorical`, `boxplot`, `radar` 필드를 검사하던
  테스트를 공통 Config·SeriesConfig, 리소스 연결, 데이터 보존과 실제 출력 검사로
  이관했다. 새 모델이 지원하는 축 범위·범례 위치와 큰 글꼴도 검사한다.

### 당시 상위 렌더러에서 막힌 조합

일반 Cartesian 루트 옆에 배치한 혼합 서브플롯 22종을 추가 검사했다.
Native 등록·렌더링은 19종이 통과했고, `EnergyLevels`, `Ternary`, `Parallel`
3종은 해당 서브플롯 대신 루트 좌표계로 검증되어 거부된다. notebook 모델은
22종을 구성하지만, 이 3종은 실제 공개 WASM `set_config()` 호출에서도 같은
오류를 재현했다. 단독 차트는 정상이다.

[figgy #325](https://github.com/shim9610/figgy/issues/325)에 재현과 원인을
영문으로 보고했다. 이 3개 native 회귀는 해당 오류만 허용하는 strict xfail이며,
상위 수정 뒤에는 XPASS로 실패하도록 해 두었다. 루트 축을 바꾸는 우회는 하지 않는다.
정식 배포 조건에 이 조합의 재검증을 포함한다.

거부한다. 고급 모델의 코드가 항상 짧은 편의 API 호출로만 표현되는 것은 아니다.
재질의 미세한 grain은 GPU에 등록된 시리즈 ID를 seed로 사용하므로 독립 Figure의
픽셀 비교에서는 Flat 재질 또는 채널당 3/255 이하 오차를 사용하는 검사가 있다.

### NIST 입력

`read_nist(levels, lines=None)`는 CSV 경로·본문·텍스트 스트림·테이블을 읽고
configuration/term/J로 전이 끝점을 연결한다. 단위·수치 한정 기호·불확도·참고문헌을
보존한다. 표에 없는 준위의 전이는 기본적으로 오류이며 `unmatched='skip'`을
명시한 경우에만 제외 개수를 기록한다. URL 다운로드·단위 변환·전이 추론은 별도다.

| 실제 입력 | 준위 | 전이 | 이온화 한계 | 연결 누락 |
| --- | --- | --- | --- | --- |
| He I | 59 | 111 | 1 | 0 |
| Cu I | 35 | 69 | 1 | 0 |
| Ar I | 43 | 51 | 1 | 0 |

입력 원본은 [NIST 회귀 데이터](../tests/data/nist/README.md), 사용법은
[Python API 안내](RENDERER_019.md), 최종 배포 절차는 [PUBLISHING.md](PUBLISHING.md)를 따른다.
